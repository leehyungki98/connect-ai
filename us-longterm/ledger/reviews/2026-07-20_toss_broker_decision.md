## 내 추정이 틀렸던 지점 (정정 기록)

앞선 비용 모델은 "일반적 국내 증권사" 가정이었고, **네 군데가 틀렸다.**

| 항목 | 내 추정 | 토스 실제 | 오차 |
|---|---|---|---|
| 거래 수수료 | 0.25% | **0.1%** | 2.5배 과대 |
| 소액 주문 | 최소 수수료 $0~2 부과 가정 | **$10 이하 면제** | **방향이 반대** |
| 환전 스프레드 | 0.1% | **장중 0.05% / 장외 0.5%** | 시간대에 10배 차이 |
| SEC 수수료 | 0.0028% | 0.00206% (최소 $0.01) | 과대 |

### 가장 중요한 정정 — 규모 효과의 방향
앞선 기록에서 **"최소 수수료가 작은 자본을 때린다"** 고 썼는데, 토스에는 최소
수수료가 없고 **최소 면제**만 있다. 즉 소액 주문이 페널티가 아니라 **혜택**을 받는다.
작은 자본이 비용률에서 불리하다는 결론은 **토스에서는 성립하지 않는다.**

일반론(고정비가 규모 의존성의 원천)은 여전히 맞지만, **이 증권사에는 그 고정비가
없다.** 추정으로 세운 모델을 실제 수수료표로 검증했더니 부호가 뒤집힌 사례다.

## 재측정 결과 (2016-01 ~ 2025-12, 토스 조건)

| 자본 | 총 거래비용 | 자본 대비 |
|---|---|---|
| $5,060 (실제) | $23.89 | **0.47%** |
| $20,000 | $94.17 | 0.47% |
| $100,000 | $470.70 | 0.47% |

- 이전 추정(0.25% 수수료 + 0.1% 환전) 대비 **총비용이 절반 이하** (1.15% → 0.47%)
- **완전한 규모 무관.** 단 이번엔 모델 결함이 아니다 — 토스에 고정비가 실제로 없고
  소수점 매매가 되므로 이산화도 없다. **규모 무관이 정당하게 성립한다.**
- $10 면제는 **이 데스크에서 한 번도 발동하지 않는다.** 밴드 이탈이 트리거되려면
  NAV 의 5%p 이상이 어긋나야 하고, $5,060 기준으로도 그건 $253 이라 항상 $10 을
  훨씬 넘는다. 모델에는 정확성을 위해 남기되 **실효 없음**으로 기록한다.

## 도출된 운용 규칙

### 1. 환전은 반드시 한국 장중에 한다 (09:00~15:30, 영업일)
스프레드가 **0.05% vs 0.5% — 10배** 차이다. 750만원 환전 시 **3,750원 vs 37,500원**.
코드가 강제할 수 없는 사람의 규칙이라 README·CLAUDE.md 에 명시한다.

### 2. 소수점 매매는 요건이다 (토스는 지원 — 조건 충족)
현재가 기준 정수 주로는 GROWTH 이탈 −16.66% 로 밴드(±5%) 안에 들어올 수 없다.
META 1주($646) > 목표 슬롯($506) 이라 한 주도 못 산다. 토스는 1,000원 단위
소수점 매수를 지원하므로 **이 요건은 충족**된다. 증권사를 바꾼다면 이 조건부터 확인.

### 3. 주식모으기(매수 수수료 평생 무료)는 지금 구조에 맞지 않는다
토스의 '주식모으기' 는 정기 자동매수 서비스다. 이 데스크는 분기 밴드 리밸런싱이라
매수·매도가 섞이고 금액이 매번 달라 그대로 얹을 수 없다. 다만 **분기 매수분만이라도
수수료 0** 이 되는지는 실계좌 전환 시 확인 가치가 있다 (연 0.1%×매수액 절감).
→ 실계좌 전환 체크리스트로 넘긴다.

## 토스 Open API — 자동화 선택지가 생겼다 (지금은 행동 없음)

토스증권이 2026년 5월 개인용 Open API 사전신청을 시작했고 **미국 주식 주문을
지원**한다. 정식 오픈일은 미발표, 단계적 개방 중.

미장팀 관점:
- **지금 필요 없다.** 분기 4회 수동 실행이라 API 없이도 완전히 운용 가능하다.
- 자동화는 DESKS.md 의 게이트(분기 사이클 1회 무사고 완주 + 항목별 개별 승인)를
  통과한 뒤의 이야기다. API 가 생겼다는 이유로 게이트를 건너뛰지 않는다.
- 스윙팀(KIS 자동매매)의 이전 검토는 **별도 건**이다. 미장팀이 판단할 사안이 아니다.
