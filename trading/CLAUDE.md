# trading — 프로젝트 규칙 (모의투자 전용)

## 절대 규칙
- 편집 금지 구역: `autotrader/safety/`, `autotrader/gates/`, `autotrader/config.py`.
  안전층(킬스위치·일일손실한도·리스크/컴플라이언스 게이트)은 100% 결정적 코드 — LLM 호출 금지.
- 실거래 API 연결 금지. KIS 모의투자 도메인·VT TR ID만 허용 (컴플라이언스 게이트가 강제).
- `.env`·`state/` 내용 출력·커밋 금지.
- "완료/검증됨" 보고 전에 실제 테스트 출력으로 뒷받침. 안 돌렸으면 "미검증" 명시.
- 전략 파라미터 변경은 백테스트 게이트(독립 기간에서 V0 대비 MDD↓·샤프↑) 통과 +
  사용자 승인 후에만. 같은 데이터에 반복 최적화 금지.

## 트레이딩 영구 규칙 (변경 제안 큐에서 승격)
- [2026-07-19] C2 파라미터 조건부 채택 (사용자 승인): 손절 쿨다운 10거래일,
  손절 거리 하한 clamp(2.5σ20, 2%, 10%), 시장 폭 필터 0.5, 일별 신규 진입 2종목.
  근거: 2년 백테스트에서 MDD 4/4 구간 개선 (7.0~20.4% vs V0 22.2~38.9%).
  관찰 조건: 약세·횡보 국면 샤프 열위(2024 전반 -1.42 vs V0 -0.14) — 모의 운용에서
  해당 국면 도래 시 성과를 관찰하고, 약세 국면 진입 강화 카드의 재료로 쓴다.
  엄격 게이트(샤프 4/4)는 불통과였음을 기록해 둔다 — 사후 합리화 금지.

## 운용 명령
- 장 시작 전: `python scripts/run_premarket.py` (C2 제약 내장)
- 마감 후: `python scripts/run_postmarket.py --review`
- 백테스트: `python scripts/run_backtest.py` (채택 파라미터) / `--compare` (V0 대비)
- 테스트: `python -m pytest tests/ -q` — 코드 변경 시 반드시 전체 통과 확인
