# 백테스트 자율 탐색 미션 (Claude Code · Fable 5 전용)
작성일: 2026-07-19 | 대상: connect-ai/trading | 전제: pytest 214개 통과 상태에서 시작
근거: 1년 백테스트(645트레이드) 실패 패턴 분석 — stop 손실의 58%가 1봉 노이즈 컷,
82%가 반복 손절 종목, 52%가 시장 동시 하락일에 집중.

---

## 목표 (왜부터)

기본 전략의 손실이 손절 구조에서 나온다는 진단을 실데이터로 검증하고,
P2(쿨다운)·P1(변동성 손절)·P3(시장 필터) 파라미터의 강건한 조합을 찾아라.
목적은 수익 극대화가 아니라 **리스크조정 수익(샤프)과 MDD 개선**이다.
절대수익은 관찰만 한다. 이 결과는 모의투자 운용 기본값의 근거 자료가 된다.

## 절대 제약 (위반 금지)

1. 편집 금지 구역: `autotrader/safety/`, `autotrader/gates/`, `autotrader/config.py`.
   백테스트 개선은 `autotrader/backtest.py`, `scripts/run_backtest.py`, `tests/`만 건드린다.
2. 실거래 API 연결 금지. KIS 주문 코드(`autotrader/kis/`)는 이 미션과 무관 — 손대지 마라.
3. `.env`·`state/` 내용을 출력·커밋하지 마라.
4. KRX 데이터는 **한 번만 수집**하고 로컬 캐시(`state/bars_cache.json` 등)로 재사용하라.
   반복 원격 조회는 차단당한다(실측: 무지연 시 ~50건째부터 응답 중단, 0.25초 페이싱 필수).
5. 파라미터 기본값 변경·git 커밋·push는 하지 마라. 결과는 보고서로만 제안한다.
   (기본값 승격은 사용자 승인 지점이다.)

## 과최적화 게이트 (채택 기준 — 결정적)

- 데이터를 날짜 기준 전반/후반으로 나눠 **양쪽 구간 모두** V0 대비
  MDD 감소 AND 샤프 상승인 조합만 "채택 후보"로 표기한다.
- 한쪽 구간에서만 좋아지는 조합은 기각하고 기각 사유를 기록한다.
- 백테스트 총 실행 횟수 상한: 40회. 탐색 공간:
  cooldown_bars {3,5,10} × stop_vol_k {1.5,2.0,2.5} × market_breadth_min {None,0.3,0.4,0.5}
  × max_new_per_day {None,2,3}. 전수 탐색 금지 — 축별 순차 탐색(P2→P1→P3)으로 좁혀라.

## 작업 방식

- 시작 전 `python -m pytest tests/ -q` 로 214개 통과를 확인하고, 코드를 고쳤다면
  매번 다시 돌려라. 테스트 실패 상태로 다음 단계로 넘어가지 마라.
- 진행 상황을 보고하기 전에 각 주장을 이 세션의 도구 실행 결과와 대조해 검증하라.
- 요청 범위를 넘는 기능·리팩토링·추상화를 추가하지 마라.
- 행동할 만큼 정보가 모이면 즉시 행동하라. 결과부터 말하라.
- 실험 기록: `state/experiments.md`에 실험당 한 줄
  (`파라미터 | 전반 ret/mdd/sharpe | 후반 ret/mdd/sharpe | 판정 | 교훈`)을 append 하라.
  이 파일이 이 미션의 메모리다 — 같은 실험을 반복하지 마라.

## 종료 조건과 산출물

다음 중 하나면 종료: (a) 채택 후보 1~3개 확정, (b) 40회 상한 도달,
(c) 어떤 조합도 게이트를 못 넘는다는 결론.

최종 보고서(`state/backtest_mission_report.md`):
1. 채택 후보 파라미터와 근거 수치 (전/후반 표)
2. 기각된 조합과 이유 (한 줄씩)
3. V0 대비 stop 비중·1봉 컷 비율·동시 손절일 손실의 변화
4. 남은 불확실성과 다음 검증 제안 (예: 다른 1년 구간 재검증)
5. 미검증 항목은 "미검증"으로 명시

## 참고 (현재 코드 상태)

- `BaselineParams`: cooldown_bars / stop_vol_k / market_breadth_min / max_new_per_day
  전부 파라미터화 완료, 기본값 OFF. `run_backtest()`는 순수 함수 — 같은 입력 같은 출력.
- `scripts/run_backtest.py --compare`: V0→V3 누적 4변형 × 전/후반 표 출력 + JSON 저장.
  탐색 루프는 이 스크립트를 고치기보다 데이터 캐시를 로드해 `run_backtest()`를
  직접 호출하는 별도 스크립트(`scripts/run_sweep.py` 신규)로 만드는 편이 빠르다.
- 실패 패턴 원자료: `state/backtest_20250716_20260716.json`의 `trade_log`.
